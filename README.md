# ⚙️ GIF 全能魔术工具箱 (GIF Master)

一款专为 AstrBot 打造的终极 GIF 处理工具箱，集成了魔性特效、视频高速转换、全动态套娃表情包以及趣味互动表情模板。

---

## 🎮 功能介绍

### 1. GIF 特效魔术（回复图片/GIF）

长按回复任意图片/表情包，或在发送图片的同时输入以下指令：

| 指令 | 效果 | 适用 |
|------|------|------|
| `/gif倒放` | 反向播放动图 | 仅动图 |
| `/gif回弹` | 正向+反向循环播放 | 仅动图 |
| `/gif左右翻转` | 左右镜像翻转 | 图片/动图 |
| `/gif上下翻转` | 上下镜像翻转 | 图片/动图 |
| `/gif旋转` | 顺时针旋转 90° | 图片/动图 |
| `/反色` | 颜色反转（底片效果） | 图片/动图 |
| `/gif变速 2.0` | 调节播放速度（数字为倍数） | 图片/动图 |

> 💡 指令支持多种写法，例如 `/GIF倒放`、`/左右翻转`、`/调速` 等。

### 2. 对称镜像（回复图片/GIF）

将图像的一半镜像对称到另一半，生成独特的视觉效果：

| 指令 | 效果 |
|------|------|
| `/左对称` | 左侧镜像到右侧 |
| `/右对称` | 右侧镜像到左侧 |
| `/上对称` | 上部镜像到下部 |
| `/下对称` | 下部镜像到上部 |

### 3. 视频转 GIF 卡片（回复视频）

长按回复群聊里的视频文件或小视频，输入：

- `/转GIF` – 使用默认参数转换。
- 精细控制参数：  
  `/转GIF -w 320 -s 1.5 -r -rot 90`  
  - `-w`：输出宽度（像素）  
  - `-s`：速度倍数  
  - `-r`：倒放  
  - `-rot`：旋转角度（90/180/270）

### 4. 全动态行内套娃表情包

长按引用/回复任意 GIF 动图，使用 `<>` 或 `{}` 作为内嵌动图的占位符：

- `/makegif 要我一直<>吗？`
- `/makegif 震惊！{}怎么会这样`

**效果**：上方原尺寸动图，下方自定义文字，文字中间包裹着同步帧率的缩小版原动图 —— 真正的“套娃”效果。背景为实色（白或黑），文字颜色自动适应背景。

### 5. 趣味互动表情模板

| 指令 | 说明 | 互动方式 |
|------|------|----------|
| `/摸头` | 摸头杀 | 自动使用发送者头像 |
| `/发射` | 发射人物头像 | 自动使用发送者头像 |
| `/杀` | 砍头特效 | 自动使用发送者头像 |
| `/操你 @用户` | 撅人互动 | 需要 @ 目标用户 |
| `/抽你 @用户` | 鞭笞互动 | 需要 @ 目标用户 |

> 若未检测到图片，插件会自动尝试获取发送者或被 @ 用户的 QQ 头像（需在配置中开启 `enable_at_avatar`）。

## ⚙️ 配置说明

在 AstrBot Web 面板或插件配置文件中可调整以下参数：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `send_mode` | string | `发送图片/表情包` | `发送图片/表情包`（直接发图）或 `作为文件发送`（避免画质压缩） |
| `enable_at_avatar` | bool | `true` | 是否允许无图片时通过 @ 用户获取头像（仅模板指令有效） |
| `max_size_mb` | int | `10` | 允许处理的最大输入文件大小（MB） |
| `default_width` | int | `400` | 视频转 GIF 的默认宽度（px） |
| `max_width` | int | `720` | 视频转 GIF 的最大宽度上限 |
| `default_fps` | int | `15` | 视频转 GIF 的默认帧率 |
| `font_size` | int | `24` | 套娃表情包文字大小（px，注：代码中实际动态缩放，此配置未生效） |
| `bg_style` | string | `white` | 套娃文字颜色自适应（`white` 黑字 / `black` 白字） |
| `font_path` | string | `""` | 自定义字体路径（留空自动匹配系统字体） |

## ❓ 常见问题

**Q: 套娃表情包背景不是透明的？**  
A: 当前版本背景为实色（白或黑）。若需要透明背景，请修改 `meme/nested.py` 中的 `bg_color = (0,0,0,0)`。

**Q: `/gif变速 2.0` 在手机上反而变慢了？**  
A: 这是手机端的高帧率防御机制。插件已将最小帧间隔设为 30ms，可缓解但仍建议尝试 1.5~1.8 倍速。

**Q: 长按引用消息有时识别不到图片？**  
A: 确保机器人 API 支持 `get_msg` 和 `get_group_file_url`。若仍有问题，可直接发送图片而不使用引用。

**Q: 为什么没有 `/gif翻转` 指令了？**  
A: 为避免歧义，已拆分为 `/gif左右翻转` 和 `/gif上下翻转`，请使用明确方向的指令。

**Q: `font_size` 配置不生效？**  
A: 套娃文字大小根据原图宽度动态计算，配置中的 `font_size` 暂未使用，如需固定大小可修改 `nested.py`。
